# ★ BlogStar

**Just Your Thoughts.**

A little place on the internet to write, share ideas, and make something worth reading.

BlogStar is a simple, GitHub-powered blogging platform built with React, Vite and JavaScript.

No complicated publishing systems. Just write your thoughts, add them to the content, and let BlogStar do the rest.

## What's inside?

- ✍️ Write and publish blog posts.
- 📝 JSON-powered content.
- 🏷️ Tags and categories.
- 🔎 Explore and discover posts.
- 💻 Code presentation.
- 🖼️ Images and rich media.
- 🌗 Light and dark themes.
- 📱 Mobile-friendly design.
- ⭐ GitHub repository star link.

## What can you write about?

Pretty much anything.

- Programming and development
- Useful websites and tools
- Open-source discoveries
- Technology and experiments
- Tutorials and guides
- Internet culture and memes
- Funny tech company moments
- Personal thoughts and experiences

You don't have to be an expert to write something interesting.

## Getting started

You'll need Node.js and npm.

```bash
git clone https://github.com/spideythedev/blogstar.git
cd blogstar
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Adding your own blog

Visit `/guide` to learn how to add posts, structure JSON content, use tags and work with supported content formats.
